## What this site collects

This is a statically generated website. It has no server-side application, no user
accounts and no first-party database. Loading a page does not create a record on a
server controlled by the project.

## Cookies

This repository sets no cookies. Any cookie banner you see on a deployed instance
comes from a third-party service added by the operators of that deployment, not from
the site source.

## Analytics

No analytics script is included in this repository. If an operator adds one, it will
be visible in the page source and is responsible for its own disclosure.

## Contact

Questions about privacy can be sent to team@ergoplatform.org, or raised as an issue on
the project's GitHub repository.
