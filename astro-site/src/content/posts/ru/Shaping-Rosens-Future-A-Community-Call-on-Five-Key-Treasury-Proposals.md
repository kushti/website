Соучредитель Rosen, Armeanio, представил пять новых предложений в казначейство Rosen. Эти предложения описывают стратегическое видение роста, полезности и масштабируемости моста Rosen, ключевого компонента инфраструктуры совместимости Ergo.

Это критический момент для сообщества Ergo, чтобы рассмотреть и обсудить будущее направление этой жизненно важной кросс-цепной услуги. Ниже приведен краткий обзор каждого предложения. Мы призываем вас ознакомиться с ними и участвовать в последующих обсуждениях.

### [Предложение 1: Увеличение ликвидности RSN через неинфляционные пары блокировки казначейства](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-1-77c3849ed71e)

* **Суть:** Выделить 30% от сборов казначейства Rosen для создания ликвидных пулов децентрализованной биржи (DEX) для родного токена Rosen (RSN), сочетая его с активами, такими как ERG, rsADA и rsBTC.
* **Цель:** Увеличить рыночную глубину RSN для более эффективной торговли, особенно для Наблюдателей, которые обеспечивают безопасность моста. Это будет достигнуто без создания новых токенов, а сборы LP будут реинвестированы в казначейство для устойчивого роста.
* **Запрос:** Утвердить выделение 30% сборов казначейства для этих ликвидных пулов DEX.

### [Предложение 2: Расширение полезности RSN с помощью Hodl Game + (Рамочная программа доходных облигаций)](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-2-f702bea21b6d)

* **Суть:** Ввести "Hodl Game +," протокол DeFi, где пользователи могут блокировать свои RSN.
* **Цель:** Создать более стабильный рынок RSN, вознаграждая долгосрочных держателей. Система предлагает раздачу 2,5% от всех сборов моста участникам и введение штрафа в 2,5% за выход, который также будет финансировать раздачи. Эта рамочная программа разработана для модульного использования в будущих интеграциях цепей.
* **Запрос:** Утвердить выделение 2,5% сборов для раздач и авторизовать пилотную программу для Hodl Game +.

### [Предложение 3: Вознаграждение наших партнеров SPO и увеличение видимости Ergo и моста Rosen](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-3-rewarding-our-spo-partners-and-growing-ergo-and-rosen-bridge-visibility-aa6900fcb7f0)

* **Суть:** Укрепить связь Ergo и Cardano, вознаграждая операторов пулов ставок Cardano (SPO), которые поддерживают мост Rosen.
* **Цель:** Раздать 10% вознаграждений ERG моста кошелькам, ставленным с партнёрскими SPO. Это будет служить как вознаграждение за их поддержку, так и стратегической инициативой для увеличения числа держателей rsERG на Cardano, что является ключевым показателем для листинга на биржах.
* **Запрос:** Необходима обратная связь от сообщества по технической и финансовой осуществимости выполнения этой раздачи в сети Cardano.

### [Предложение 4: Инвестиции для расширения и инструментов](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-4-investing-for-expansion-and-tooling-0ba9f7498ccd)

* **Суть:** Запрос на финансирование для создания необходимой инфраструктуры для ускорения развития Rosen.
* **Цель:** Предложение описывает три ключевых области: **SigmaChain Framework** для упрощения новых интеграций блокчейнов, **Rosen Fast DeFi Framework** для премиум, высокоскоростного моста и **Улучшения Ergo DEX** для повышения прибыльности LP.
* **Запрос:** Это призыв к обсуждению в сообществе для определения дорожных карт, структур вознаграждений и необходимых сумм финансирования из казначейства.

### [Предложение 5: Стимулы для стандартов вклада Rosen](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-5-incentives-for-rosen-contribution-stardards-9f5cabeed7f9)

* **Суть:** Децентрализовать интеграцию новых блокчейнов, создав стандартизированную модель стимулов для внешних разработчиков.
* **Цель:** Предложить внешним разработчикам 5% от сборов за исходящие транзакции с любой новой цепи, которую они успешно интегрируют, при условии, что они соблюдают Стандарты вклада Rosen (RCS) и обязуются к постоянному обслуживанию.
* **Запрос:** Установить четкую и вознаграждающую рамочную программу, которая использует глобальные таланты разработчиков для масштабирования экосистемы Rosen безопасным и устойчивым образом.
