[A multisig wallet ](https://www.bitstamp.net/learn/security/what-is-a-multisig-wallet/)is a “digital wallet that operates with multisignature addresses. This means that it requires more than one private key to sign and authorize a crypto transaction or, in some cases, that several different keys can be used to generate a signature.” The reason that this type of wallet is valuable to an ecosystem is because it adds a second layer of protection to the end user. A multisig wallet requires that everyone with a private key confirms the transaction in order for it to be authorized and executed. This provides an added layer of security for protection against hacks because an attacker would need all of the private keys in order to gain access to the wallets funds.
