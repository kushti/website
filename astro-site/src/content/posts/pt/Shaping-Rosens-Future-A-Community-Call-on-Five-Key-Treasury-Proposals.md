O co-fundador da Rosen, Armeanio, apresentou cinco novas propostas ao Tesouro de Rosen. Essas propostas delineiam uma visão estratégica para o crescimento, utilidade e escalabilidade da Rosen Bridge, um componente central da infraestrutura de interoperabilidade do Ergo.

Este é um momento crítico para a comunidade do Ergo revisar e discutir a direção futura deste serviço vital de cross-chain. Abaixo está um resumo conciso de cada proposta. Pedimos que você as leia e participe das discussões subsequentes.

### [Proposta 1: Aumentando a Liquidez do RSN Através de Pares de Bloqueio de Tesouraria Não Inflacionários](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-1-77c3849ed71e)

* **A Essência:** Alocar 30% das taxas do Tesouro de Rosen para criar pools de liquidez de troca descentralizada (DEX) para o token nativo de Rosen (RSN), emparelhando-o com ativos como ERG, rsADA e rsBTC.
* **O Objetivo:** Aumentar a profundidade do mercado de RSN para permitir negociações mais eficientes, particularmente para os Watchers que garantem a ponte. Isso seria realizado sem a emissão de novos tokens, e as taxas de LP seriam reinvestidas no tesouro para um crescimento sustentável.
* **O Pedido:** Aprovar a alocação de 30% das taxas do tesouro para esses pools de liquidez DEX.

### [Proposta 2: Expandindo a Utilidade do RSN com o Hodl Game + (Uma Estrutura de Títulos de Receita)](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-2-f702bea21b6d)

* **A Essência:** Introduzir "Hodl Game +," um protocolo DeFi onde os usuários podem bloquear seu RSN.
* **O Objetivo:** Criar um mercado de RSN mais estável recompensando os detentores de longo prazo. O sistema propõe airdropar 2,5% de todas as taxas da ponte para os participantes e instituir uma penalidade de 2,5% para a saída, que também financiaria os airdrops. Esta estrutura é projetada para ser modular para futuras integrações de cadeia.
* **O Pedido:** Aprovar uma alocação de taxa de 2,5% para airdrops e autorizar um programa piloto para o Hodl Game +.

### [Proposta 3: Recompensando nossos Parceiros SPO e Aumentando a Visibilidade do Ergo e da Rosen Bridge](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-3-rewarding-our-spo-partners-and-growing-ergo-and-rosen-bridge-visibility-aa6900fcb7f0)

* **A Essência:** Fortalecer a conexão Ergo-Cardano recompensando os Operadores de Pool de Stake do Cardano (SPOs) que apoiam a Rosen Bridge.
* **O Objetivo:** Airdropar 10% das recompensas de ERG da ponte para carteiras apostadas com SPOs parceiros. Isso atua tanto como uma recompensa pelo apoio deles quanto uma iniciativa estratégica para aumentar o número de detentores de rsERG no Cardano, que é uma métrica chave para listagens em exchanges.
* **O Pedido:** O feedback da comunidade é necessário sobre a viabilidade técnica e financeira de executar este airdrop na rede Cardano.

### [Proposta 4: Investindo para Expansão e Ferramentas](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-4-investing-for-expansion-and-tooling-0ba9f7498ccd)

* **A Essência:** Um pedido de financiamento para construir a infraestrutura essencial para acelerar o desenvolvimento de Rosen.
* **O Objetivo:** A proposta delineia três áreas de foco: um **Framework SigmaChain** para simplificar novas integrações de blockchain, um **Framework Rosen Fast DeFi** para bridging premium e de alta velocidade, e **Melhorias no DEX do Ergo** para melhorar a rentabilidade de LP.
* **O Pedido:** Esta é uma chamada para discussão da comunidade para definir os roteiros, estruturas de recompensas e montantes de financiamento necessários do tesouro.

### [Proposta 5: Incentivos para Padrões de Contribuição de Rosen](https://curiaregiscrypto.medium.com/rosen-treasury-proposal-5-incentives-for-rosen-contribution-stardards-9f5cabeed7f9)

* **A Essência:** Descentralizar a integração de novas blockchains criando um modelo de incentivo padronizado para desenvolvedores externos.
* **O Objetivo:** Oferecer aos desenvolvedores externos 5% das taxas de transação de saída de qualquer nova cadeia que eles integrem com sucesso, desde que cumpram os Padrões de Contribuição de Rosen (RCS) e se comprometam com a manutenção contínua.
* **O Pedido:** Estabelecer uma estrutura clara e recompensadora que aproveite o talento global de desenvolvedores para escalar o ecossistema de Rosen de maneira segura e sustentável.
